# Changelogs

## v1.2.7

UI UX Improvements

- 更新主题管理缩略图，清理旧 SAO 字样；tar 与 zip 打包均同步最新预览图。
- 首页曲线弹窗改为逐行「线路名 延迟 ms (丢包率)」，收紧曲线及弹窗留白。
- 英文与繁体中文紧凑丢包标签改用 PLR，详情提示的丢包率仅保留括号百分比。
- Ping 双轴共用水平网格线，去掉突出刻度与色带说明，调整图例、线路按钮间距。
- Load、Ping 标题和工具栏在宽屏紧凑同行，空间不足时整组换行并左对齐。

## v1.2.6

Feat: new latency display option & package loss bar.

- 首页延迟支持方块与曲线切换，同步查看当前节点所有线路在同一时刻的延迟和丢包率。
- Ping 历史新增带独立右轴的丢包柱状图，按丢包程度显示黄、橙、红，并优化窄屏清晰度。
- 清理界面 SAO 文案，默认站点名改为 Monitor，默认矩阵预设改为 JKSR。

## v1.2.5

Bug fix: 修复月流量重置未能正确显示

- 卡片与实例详情的月额度优先使用后台 `month_used`；缺失时仅用有效周期上下行按后端 `sum / up / down / max` 模式计算，未知模式按 `sum`。
- 保留周期刚重置时的有效零值，统一在线、离线、首次加载、轮询及 WebSocket 更新；无周期数据时显示暂无数据。
- 累计上下行保留独立统计并明确标注；额度沿用 1024 进制并显示两位小数，超额时剩余不低于零、进度不超过 100%，保留实际用量。

## v1.2.2

本次更新优化移动端布局与多语言文案，保留已有设置和线路展示规则。

- **续费提醒弹窗**：手机端独立按屏幕定位，避免卡片悬浮动效将弹窗压成窄条；文字、价格、状态和按钮不再重叠，关闭后不会因焦点恢复自动重新弹出。
- **资产页排序**：手机端将排序控件放在独立一行，服务器数量保持完整显示；320px 屏幕下四个排序选项和方向按钮均可直接使用。
- **紧凑卡片**：信息条保持一行四格，英文到期天数使用 `d`，计费周期使用 `m/q/y` 等缩写；保留多月、多年周期信息。
- **首页排版**：地区标签采用等宽字体与统一宽度槽位；移除集群和服务器列表的冗长描述并收拢留白，缩短英文带宽及总览文案。
- **繁体中文**：使用「伺服器」「硬碟」「記憶體」「網路」「預設」「儲存」等台湾地区常用界面用语；节点名、任务名和用户输入仍保持原文。
- **缓存更新**：修改的生产 JS/CSS 使用新的内容哈希 URL，旗帜文件未改动。

## v1.2.1

选择性移植上游 v1.2.0 的新增功能，保留 Mod 的逐服务器多线路、静默更新、丢包色带、语言切换、资产标签与矩形旗帜。

- **四款矩阵配色**：经典标准、EVA 初号机、夜之城 2077、命运石之门；支持激光横扫、数码雨流、神经故障、世界线跳变四种开屏动效。
- **自定义状态光柱**：流量用量支持 18 段连续色谱预览；延迟和丢包支持调整判断门槛与各档颜色。经典运维、深邃冰火、深海青翠三套预设可联动应用到三种光柱，也可单独重置。
- **设置自动保存**：主题设置分为「首页」「服务器」「资产」。合法修改防抖自动保存，连续修改串行提交；失败保留草稿，可点击状态按钮重试。无效门槛或未完成的自定义线路暂停保存，修正后继续。
- **资源缓存更新**：旗帜使用 `/assets/flags-rect-v1.2.1/` 新目录；生产 JS/CSS 使用内容哈希文件名，避免沿用旧资源 URL。
- **单平台整理**：请求、类型和开发文档统一面向极简探针；保留旧 Mod 的必要缓存键，升级不清空访客偏好。
