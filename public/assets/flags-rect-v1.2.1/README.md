# Rectangular flags

4:3 SVG flags from [lipis/flag-icons](https://github.com/lipis/flag-icons), version 7.5.0, distributed under the included MIT LICENSE.

Bundled locally for use by the shared Flag component; no external image requests are required.

The versioned `/assets/flags-rect-v1/` directory replaces the old `/assets/flags/` URLs so previously cached circular SVGs cannot be reused. Increment the directory version when replacing these assets again.

Legacy region aliases `ac`, `ta`, and `ea` retain rectangular assets for existing configurations.
